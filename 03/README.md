# Day 3: Calendar Conflict Detection Agent

Welcome to Day 3 of the **100 Days of Agentic AI Challenge**!

## 📌 Overview

**Agent Type**: 🤖 Rule-Based Agent
**Role**: 📅 Calendar Manager

In this challenge, you will build a smart **Calendar Conflict Detection Agent** that reads a weekly calendar, detects overlaps or tight handoffs, and recommends what to fix first.
